Pair with GitTerm

This phone gets its own key to the chats on this machine. GitTerm can revoke it at any time.

  1. Tap Share (the square with an arrow), then Add to Home Screen.
  2. Open GitTerm from the home screen.
  3. Type the code shown in GitTerm, under the QR code.

The app keeps its own pairing, apart from Safari’s, so this link is not used up: the code in GitTerm still works.
