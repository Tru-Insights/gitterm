# TRU-274 — Iced → GPUI interaction map

## First: controls that can execute, persist, or leave the current view

**Do not use a green `▶ command` as a disclosure.** In either implementation it can start/restart that repository's command. A live matching run is focused instead. The panel toggle is a different control.

Risk key used throughout: **P** starts/sends input to/stops a process (including agents); **W** writes durable data; **X** opens an external application, browser, URL or native picker; **C** writes the clipboard; **R** runs read-only discovery, possibly using subprocesses. An action opening a confirmation is marked for the eventual confirmed effect, not as an assertion that the first click writes immediately. Ordinary in-memory disclosure/filter changes are unmarked. Layout/session selection can also save UI state; that is listed separately below.

Remembered permission can write `.claude/settings.local.json` (H18); PR confirmations publish changes (W19/D23); unmanaged-worktree Remove starts removal directly (G06), while task deletion uses a confirmation (T08). Terminal paste can execute commands (B11/M10). Theme, mirroring, repo membership, run-command edits, workspace/task lifecycle, pairing/revocation and routing pins are writes, not disclosures. These describe application behavior; none were invoked for this audit.

This is a **static source audit**, at `603ffa39aa803e891f479195c5f4b2808d44b2ad` (the task base), not a runtime certification. No app was launched or driven. Iced is the behavioral baseline, including inconvenient or surprising behavior. GPUI component outcomes are traced to mounted shell handlers: a matching enum without its effect is **DIFF**.

The owner's reported incident was clicking the green Run button while seeking the collapsed panel's expand affordance, which ran `cargo tauri dev`. The literal glyph discrepancy is present: [Iced header](../src/main.rs#L49388) chooses `▶`/`▼`; [GPUI controls](../gpui/crates/shell/src/bottom_panel.rs#L108) always choose `▼`. **At this revision both mounted renderers hide the entire collapsed panel**, including the header ([Iced](../src/main.rs#L49112), [GPUI](../gpui/crates/shell/src/bottom_panel.rs#L411)). Thus the collapsed `▶` is an Iced header-state definition, not a reachable collapsed header in this checkout. The reopening path is the workspace bar's `>_` or eligible `⌘J`. The source does not establish which prior build/layout was used in the incident.

### Reading the tables

Each row is a control or a repeated control family whose instances share behavior. Letter suffixes distinguish subcontrols; references to a base ID include its suffix rows. Dynamic values are in `{braces}`. `I` means Iced; `G` means GPUI. `—` means absent/no explicit binding/tooltip in the cited application code, not a claim about operating-system accessibility behavior. **H** means hover background or text highlight; **N** means the GPUI component's native button/input hover style; **T** is a tooltip, explicitly separated from an accessibility label. A GPUI `aria_label` is not a hover tooltip. Unless a row says otherwise, activation is one left click, with **no app-specific double-click or right-click handler**. Text inputs retain native selection/editing; the transcript and terminal context menus are called out explicitly. Keyboard entries are actual app bindings; generic Tab reachability is not assumed for clickable `div`s.

`MATCH` means the stated interaction/effect matches at source level; it does not certify font rasterization, animation, platform focus behavior, or unavailable remote transports. `DIFF` names the concrete missing/changed behavior. Scope includes the mounted local shell and the Iced-only controls it needs to replace; fixture-only GPUI views are identified as such.

There is no app-defined double-click action on spine/session/work/repo/PR/usage rows in the inspected renderers. Text selection uses the underlying text system. In GPUI, numerous custom `div.on_click` controls (bottom chrome, spine dots, workspace chips) have ARIA roles but no local focus/key-activation handler; do not equate a role with keyboard reachability. Native Button, Tree, Input and Select behavior is distinct from these custom controls.

## Prioritized differences

Order is **changed click effects**, then **state glyphs**, then **focus/keyboard**, then **cosmetic/feedback**. The first fifteen are the durable handoff's top fifteen; later entries cover the remaining difference families rather than hiding them in “visual parity.”

1. **Work Run can execute while reporting unavailable** — W08/W32. `WorkSidebar::emit` reports a preview error and still emits; mounted subscribers execute Run/navigate Task. A warning is not evidence that nothing happened. [Emit](../gpui/crates/shell/src/work_sidebar.rs#L405), [subscriber](../gpui/crates/shell/src/lib.rs#L3616).
