# TRU-274 — Iced / GPUI UI parity map

Owner decision, 2026-11-20: the migration changes **only the UI framework**.
Done means the same layout, navigation, menus, shortcuts, flows and behavior as
Iced GitTerm. This map is the remaining UI backlog; migration/stage designs do
not override the running product's implementation.

## Scope and evidence

Code audit at `852cf4f7cf8e58543ecc8a680059bf1de294d049` (`origin/v6`). Sources
below are repository-relative `file:line` anchors at that revision. No GUI was
launched and no production settings, conversations, browser or provider state
was inspected. “Today” means implemented behavior in this checkout, not a
visual certification or a successful live-provider trial.

The GPUI **local shell** is the comparison target. Its explicit sample mode and
standalone chat/review fixtures are identified separately. A fixture renderer,
typed intent or shared reducer is not an integrated user flow.

Statuses apply to the specific behavior in each row:

- **same** — the cited behavior exists on both sides; this does not certify the
  surrounding screen, appearance or every edge case.
- **differs** — GPUI implements a counterpart with different presentation or behavior.
- **missing** — no integrated counterpart; partial/fixture code is named when present.
- **GPUI-only (must be removed)** — added product-facing behavior/chrome without
  an Iced counterpart. Remove it from the normal application surface; test
  harnesses may remain. This is not an instruction to remove preview isolation,
  authorization checks or process-cleanup safeguards.

Two baseline details matter: Iced does **not** select an arbitrary latest chat
on every workspace click, and its bottom panel does **not** imply an existing
PTY. Named work starts a chat; a restored workspace retains its active session;
a first launch without saved workspaces creates a terminal in the launch
directory, and plain-folder paths can still contain a centre terminal. Preserve
those distinctions rather than replacing one unconditional default with another.
